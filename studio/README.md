# Sanity Studio

The editing dashboard for the site's content (starting with The Archivist). It's a separate app from the website.

```sh
cd studio
npm install
npm run dev      # http://localhost:3333, log in with your Sanity account
npm run deploy   # publish the Studio online at a *.sanity.studio address
```

Content types (the forms you see in the Studio) live in `schemaTypes/`.
